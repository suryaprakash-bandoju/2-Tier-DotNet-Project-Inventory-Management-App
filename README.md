# Inventory Management App

A simple ASP.NET Core MVC web application for managing products and inventory.

## Technologies

- C#
- .NET 8
- ASP.NET Core MVC
- Razor Views
- HTML
- CSS

## Features

- View products
- Add products
- Delete products
- View total inventory
- View total stock
- View inventory value

## Requirements

- .NET 8 SDK

Check the installed version:

```bash
dotnet --version
